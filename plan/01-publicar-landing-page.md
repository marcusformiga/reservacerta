# 01 - Publicar landing page

## Objetivo

Colocar a landing page no ar para validar demanda e iniciar conversas com donos de locadoras.

## Escopo

- Publicar `index.html`, `styles.css` e `script.js`.
- Garantir carregamento correto em mobile e desktop.
- Preparar canal simples de contato.

## Passos

1. Escolher uma hospedagem estatica simples, como Netlify, Vercel, GitHub Pages ou Cloudflare Pages.
2. Configurar dominio ou subdominio.
3. Testar a pagina publicada em celular real.
4. Validar links internos do menu.
5. Validar se o CTA leva ao formulario.
6. Criar uma planilha simples para acompanhar conversas e leads enquanto a captura automatica nao estiver pronta.

## Criterios de aceite

- A pagina abre por uma URL publica.
- A primeira dobra comunica claramente o problema.
- O formulario aparece e pode ser preenchido.
- A pagina nao tem rolagem horizontal em 320px, 390px e desktop.
- O responsavel pelo projeto consegue compartilhar o link com potenciais clientes.

## Fora do escopo

- Area logada.
- Backend.
- Pagamento.
- Automacoes complexas.
